folders
-------

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../folders.html">folders</a>
   </div>

- :small:`function` :ref:`copy <folders.copy>` — Copies the given source folder into the given destination folder. Throws if the destination already contains a folder with the name of the source folder.
- :small:`function` :ref:`getFolderInfo <folders.get^folder^info>` — Get additional information about a folder.
- :small:`function` :ref:`move <folders.move>` — Moves the given source folder into the given destination folder. Throws if the destination already contains a folder with the name of the source folder.
- :small:`event` :ref:`onCopied <folders.on^copied>` — Fired when a folder has been copied.
- :small:`event` :ref:`onCreated <folders.on^created>` — Fired when a folder has been created.
- :small:`event` :ref:`onDeleted <folders.on^deleted>` — Fired when a folder has been deleted.
- :small:`event` :ref:`onFolderInfoChanged <folders.on^folder^info^changed>` — Fired when certain information of a folder have changed. Bursts of message count changes are collapsed to a single event.
- :small:`event` :ref:`onMoved <folders.on^moved>` — Fired when a folder has been moved.
- :small:`event` :ref:`onRenamed <folders.on^renamed>` — Fired when a folder has been renamed.
- :small:`type` :ref:`MailFolderInfo <folders.^mail^folder^info>` — An object containing additional information about a folder.
