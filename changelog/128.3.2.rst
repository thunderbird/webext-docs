=================================
Changelog for Thunderbird 128.3.2
=================================

The following WebExtension API changes were introduced in Thunderbird 128.3.2.


.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../menus.html">menus</a>
   </div>

- :small:`type` `MenuActionCommand <../menus.html#menus-menu-action-command>`__ — A predefined command to open an action popup.


.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../messages.html">messages</a>
   </div>

- :small:`type` `MailBoxHeaderString <../messages.html#messages-mail-box-header-string>`__ — Content may either be a single email address, or a mailbox string (see RFC 5322, section 3.4). Use `messengerUtilities.parseMailboxString <../messengerUtilities.html#messenger-utilities-parse-mailbox-string>`__ to extract the name and/or the email from the mailbox string.
