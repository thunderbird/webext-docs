Changelog for Thunderbird 128.3.2
=================================

The following WebExtension API changes were introduced in Thunderbird 128.3.2.


menus
-----

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../menus.html">menus</a>
   </div>

- :small:`type` :ref:`MenuActionCommand <menus.^menu^action^command>` — A predefined command to open an action popup.


messages
--------

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../messages.html">messages</a>
   </div>

- :small:`type` :ref:`MailBoxHeaderString <messages.^mail^box^header^string>` — Content may either be a single email address, or a mailbox string (see RFC 5322, section 3.4). Use :ref:`messengerUtilities.parseMailboxString <messenger^utilities.parse^mailbox^string>` to extract the name and/or the email from the mailbox string.
