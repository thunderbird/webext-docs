   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../menus.html">menus</a>
   </div>

- :small:`type` `OnClickData.selectedFolders <../menus.html#menus-on-click-data-selected-folders>`__ — The selected folders in the folder pane. Only available for the :value:`folder_pane` context. The :permission:`accountsRead` permission is required. The returned selection includes the folders which would be affected by a context action through Thunderbird's UI, which may not be the currently selected folders. For example, if the user has multiple folders selected and opens the context menu for a folder outside that selection, only the folder for which the context menu was opened, is returned.
- :small:`type` `OnShowData.selectedFolders <../menus.html#menus-on-show-data-selected-folders>`__ — The selected folders in the folder pane. Only available for the :value:`folder_pane` context. The :permission:`accountsRead` permission is required. The returned selection includes the folders which would be affected by a context action through Thunderbird's UI, which may not be the currently selected folders. For example, if the user has multiple folders selected and opens the context menu for a folder outside that selection, only the folder for which the context menu was opened, is returned.

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../messages.html">messages</a>
   </div>

- :small:`function` `listInlineTextParts <../messages.html#messages-list-inline-text-parts>`__ — Lists all inline text parts of a message. These parts are not returned by `messages.listAttachments <../messages.html#messages-list-attachments>`__ and usually make up the readable content of the message, mostly with content type :value:`text/plain` or :value:`text/html`. If a message only includes a part with content type :value:`text/html`, the method `messengerUtilities.convertToPlainText <../messengerUtilities.html#messenger-utilities-convert-to-plain-text>`__ can be used to retreive a plain text version. If the message is encrypted, the inline text parts of the decrypted message are listed.
- :small:`type` `InlineTextPart <../messages.html#messages-inline-text-part>`__ — An inline part with content type :value:`text/*`. These parts are not returned by `messages.listAttachments <../messages.html#messages-list-attachments>`__ and usually make up the readable content of the message, mostly with content type :value:`text/plain` or :value:`text/html`
- :small:`type` `MessageAttachment.contentId <../messages.html#messages-message-attachment-content-id>`__ — The content-id of this part. Available for related parts, which are referenced from other places inside the same message (e.g. inline images).

- :small:`type` `RegisteredContentScript.matchOriginAsFallback <../scripting.html#scripting-registered-content-script-match-origin-as-fallback>`__ — If matchOriginAsFallback is true, then the code is also injected in about:, data:, blob: when their origin matches the pattern in 'matches', even if the actual document origin is opaque (due to the use of CSP sandbox or iframe sandbox). Match patterns in 'matches' must specify a wildcard path glob. By default it is :code:`false`.
- :small:`type` `RegisteredContentScript.world <../scripting.html#scripting-registered-content-script-world>`__ — The JavaScript world for a script to execute within. Defaults to "ISOLATED".
