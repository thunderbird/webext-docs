.. role:: small

=============================
Changelog for Thunderbird 128
=============================

The following WebExtension API changes were introduced in Thunderbird 128.


.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../declarativeNetRequest.html">declarativeNetRequest</a>
   </div>

- :small:`function` `getDisabledRuleIds <../declarativeNetRequest.html#declarative-net-request-get-disabled-rule-ids>`__ — Returns the list of individual disabled static rules from a given static ruleset id.
- :small:`function` `updateStaticRules <../declarativeNetRequest.html#declarative-net-request-update-static-rules>`__ — Modified individual static rules enabled/disabled state. Changes to rules belonging to a disabled ruleset will take effect when the ruleset becomes enabled.
- :small:`property` `MAX_NUMBER_OF_DISABLED_STATIC_RULES <../declarativeNetRequest.html#declarative-net-request-m-a-x-n-u-m-b-e-r-o-f-d-i-s-a-b-l-e-d-s-t-a-t-i-c-r-u-l-e-s>`__ — The maximum number of static rules that can be disabled on each static ruleset.
- :small:`property` `MAX_NUMBER_OF_DYNAMIC_RULES <../declarativeNetRequest.html#declarative-net-request-m-a-x-n-u-m-b-e-r-o-f-d-y-n-a-m-i-c-r-u-l-e-s>`__ — The maximum number of dynamic session rules an extension can add.
- :small:`property` `MAX_NUMBER_OF_SESSION_RULES <../declarativeNetRequest.html#declarative-net-request-m-a-x-n-u-m-b-e-r-o-f-s-e-s-s-i-o-n-r-u-l-e-s>`__ — The maximum number of dynamic session rules an extension can add.


.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../scripting.html">scripting</a>
   </div>

- :small:`type` `RegisteredContentScript.matchOriginAsFallback <../scripting.html#scripting-registered-content-script-match-origin-as-fallback>`__ — If matchOriginAsFallback is true, then the code is also injected in about:, data:, blob: when their origin matches the pattern in 'matches', even if the actual document origin is opaque (due to the use of CSP sandbox or iframe sandbox). Match patterns in 'matches' must specify a wildcard path glob. By default it is :code:`false`.
- :small:`type` `RegisteredContentScript.world <../scripting.html#scripting-registered-content-script-world>`__ — The JavaScript world for a script to execute within. Defaults to "ISOLATED".
