============================
Changelog for Thunderbird 89
============================

The following WebExtension API changes were introduced in Thunderbird 89.


accounts
--------

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../accounts.html">accounts</a>
   </div>

- :small:`function` :ref:`get.includeSubFolders <accounts.get.include^sub^folders>` — Specifies whether the :ref:`folders.MailFolder <folders.^mail^folder>` in the :value:`rootFolder` property of the returned :ref:`accounts.MailAccount <accounts.^mail^account>` should populate its :value:`subFolders` property, and include all (nested!) subfolders. Defaults to :value:`false`.
- :small:`function` :ref:`getDefault.includeSubFolders <accounts.get^default.include^sub^folders>` — Specifies whether the :ref:`folders.MailFolder <folders.^mail^folder>` in the :value:`rootFolder` property of the default :ref:`accounts.MailAccount <accounts.^mail^account>` should populate its :value:`subFolders` property, and include all (nested!) subfolders. Defaults to :value:`false`
- :small:`function` :ref:`list.includeSubFolders <accounts.list.include^sub^folders>` — Specifies whether the :ref:`folders.MailFolder <folders.^mail^folder>` in the :value:`rootFolder` property of each found :ref:`accounts.MailAccount <accounts.^mail^account>` should populate its :value:`subFolders` property, and include all (nested!) subfolders. Defaults to :value:`false`.
