============================
Changelog for Thunderbird 91
============================

The following WebExtension API changes were introduced in Thunderbird 91.


addressBooks
------------

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../addressBooks.html">addressBooks</a>
   </div>

- :small:`type` :ref:`AddressBookNode.remote <address^books.^address^book^node.remote>` — Indicates if the address book is accessed via remote look-up.


addressBooks.provider
---------------------

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../addressBooks.provider.html">addressBooks.provider</a>
   </div>

The address book provider API allows to add address books, which are not stored or cached by Thunderbird itself, but are handled completely by the extension. Address books created by the this API will forward all access requests to the WebExtension.


browserSettings.colorManagement
-------------------------------

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../browserSettings.colorManagement.html">browserSettings.colorManagement</a>
   </div>

Use the :code:`browserSettings.colorManagement` API to query and set items related to color management.


cloudFile
---------

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../cloudFile.html">cloudFile</a>
   </div>

- :small:`event` :ref:`onFileDeleted.tab <cloud^file.on^file^deleted.tab>` — The tab where the upload was initiated. Currently only available for the message composer.
- :small:`event` :ref:`onFileUpload.tab <cloud^file.on^file^upload.tab>` — The tab where the upload was initiated. Currently only available for the message composer.
- :small:`event` :ref:`onFileUploadAbort.tab <cloud^file.on^file^upload^abort.tab>` — The tab where the upload was initiated. Currently only available for the message composer.


folders
-------

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../folders.html">folders</a>
   </div>

- :small:`function` :ref:`copy <folders.copy>` — Copies the given source folder into the given destination folder. Throws if the destination already contains a folder with the name of the source folder.
- :small:`function` :ref:`getFolderInfo <folders.get^folder^info>` — Get additional information about a folder.
- :small:`function` :ref:`getParentFolders <folders.get^parent^folders>` — Get all parent folders as a flat ordered array. The first array entry is the direct parent.
- :small:`function` :ref:`getSubFolders <folders.get^sub^folders>` — Get the subfolders of the specified folder.
- :small:`function` :ref:`move <folders.move>` — Moves the given source folder into the given destination folder. Throws if the destination already contains a folder with the name of the source folder.
- :small:`event` :ref:`onCopied <folders.on^copied>` — Fired when a folder has been copied.
- :small:`event` :ref:`onCreated <folders.on^created>` — Fired when a folder has been created.
- :small:`event` :ref:`onDeleted <folders.on^deleted>` — Fired when a folder has been deleted.
- :small:`event` :ref:`onFolderInfoChanged <folders.on^folder^info^changed>` — Fired when certain information of a folder have changed. Bursts of message count changes are collapsed to a single event.
- :small:`event` :ref:`onMoved <folders.on^moved>` — Fired when a folder has been moved.
- :small:`event` :ref:`onRenamed <folders.on^renamed>` — Fired when a folder has been renamed.
- :small:`type` :ref:`MailFolderInfo <folders.^mail^folder^info>` — An object containing additional information about a folder.
