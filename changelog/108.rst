=============================
Changelog for Thunderbird 108
=============================

The following WebExtension API changes were introduced in Thunderbird 108.


browserAction
-------------

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../browserAction.html">browserAction</a>
   </div>

- :small:`function` :ref:`getBadgeBackgroundColor.details.tabId <browser^action.get^badge^background^color.details.tab^id>` — Specifies for which tab the badge background color should be retrieved. If no tab is specified, the global value is retrieved.
- :small:`function` :ref:`getBadgeBackgroundColor.details.windowId <browser^action.get^badge^background^color.details.window^id>` — Will throw an error if used.

- :small:`function` :ref:`getLabel.details.windowId <browser^action.get^label.details.window^id>` — Will throw an error if used.
- :small:`function` :ref:`getPopup.details.tabId <browser^action.get^popup.details.tab^id>` — Specifies for which tab the popup document should be retrieved. If no tab is specified, the global value is retrieved.
- :small:`function` :ref:`getPopup.details.windowId <browser^action.get^popup.details.window^id>` — Will throw an error if used.
- :small:`function` :ref:`getTitle.details.tabId <browser^action.get^title.details.tab^id>` — Specifies for which tab the title should be retrieved. If no tab is specified, the global value is retrieved.
- :small:`function` :ref:`getTitle.details.windowId <browser^action.get^title.details.window^id>` — Will throw an error if used.
