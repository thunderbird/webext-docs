.. role:: small

=============================
Changelog for Thunderbird 108
=============================

The following WebExtension API changes were introduced in Thunderbird 108.


.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../action.html">action</a>
   </div>

- :small:`function` `getBadgeBackgroundColor.details.tabId <../action.html#action-get-badge-background-color-details-tab-id>`__ — Specifies for which tab the badge background color should be retrieved. If no tab is specified, the global value is retrieved.
- :small:`function` `getBadgeBackgroundColor.details.windowId <../action.html#action-get-badge-background-color-details-window-id>`__ — Will throw an error if used.
- :small:`function` `getBadgeText.details.tabId <../action.html#action-get-badge-text-details-tab-id>`__ — Specifies for which tab the badge text should be retrieved. If no tab is specified, the global value is retrieved.
- :small:`function` `getBadgeText.details.windowId <../action.html#action-get-badge-text-details-window-id>`__ — Will throw an error if used.
- :small:`function` `getLabel.details.tabId <../action.html#action-get-label-details-tab-id>`__ — Specifies for which tab the label should be retrieved. If no tab is specified, the global value is retrieved.
- :small:`function` `getLabel.details.windowId <../action.html#action-get-label-details-window-id>`__ — Will throw an error if used.
- :small:`function` `getPopup.details.tabId <../action.html#action-get-popup-details-tab-id>`__ — Specifies for which tab the popup document should be retrieved. If no tab is specified, the global value is retrieved.
- :small:`function` `getPopup.details.windowId <../action.html#action-get-popup-details-window-id>`__ — Will throw an error if used.
- :small:`function` `getTitle.details.tabId <../action.html#action-get-title-details-tab-id>`__ — Specifies for which tab the title should be retrieved. If no tab is specified, the global value is retrieved.
- :small:`function` `getTitle.details.windowId <../action.html#action-get-title-details-window-id>`__ — Will throw an error if used.
- :small:`function` `isEnabled.details.tabId <../action.html#action-is-enabled-details-tab-id>`__ — Specifies for which tab the state should be retrieved. If no tab is specified, the global value is retrieved.
- :small:`function` `isEnabled.details.windowId <../action.html#action-is-enabled-details-window-id>`__ — Will throw an error if used.
