compose
-------

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../compose.html">compose</a>
   </div>

- :small:`function` :ref:`addAttachment <compose.add^attachment>` — Adds an attachment to the message being composed in the specified tab.
- :small:`function` :ref:`getComposeDetails <compose.get^compose^details>` — Fetches the current state of a compose window. Currently only a limited amount of information is available, more will be added in later versions.
- :small:`function` :ref:`listAttachments <compose.list^attachments>` — Lists all of the attachments of the message being composed in the specified tab.
- :small:`function` :ref:`removeAttachment <compose.remove^attachment>` — Removes an attachment from the message being composed in the specified tab.
- :small:`function` :ref:`setComposeDetails <compose.set^compose^details>` — Updates the compose window. The properties of the given :ref:`compose.ComposeDetails <compose.^compose^details>` object will be used to overwrite the current values of the specified compose window, so only properties that are to be changed should be included. Modified settings will be treated as user initiated, and turn off further automatic changes on these settings.
- :small:`function` :ref:`updateAttachment <compose.update^attachment>` — Updates the name and/or the content of an attachment in the message being composed in the specified tab. If the specified attachment is a cloud file attachment and the associated provider failed to update the attachment, the function will throw an *ExtensionError*.
- :small:`event` :ref:`onAttachmentAdded <compose.on^attachment^added>` — Fired when an attachment is added to a message being composed.
- :small:`event` :ref:`onAttachmentRemoved <compose.on^attachment^removed>` — Fired when an attachment is removed from a message being composed.
- :small:`event` :ref:`onBeforeSend <compose.on^before^send>` — Fired when a message is about to be sent from the compose window. This is a user input event handler. For asynchronous listeners some `restrictions <https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/User_actions>`__ apply.
- :small:`event` :ref:`onIdentityChanged <compose.on^identity^changed>` — Fired when the user changes the identity that will be used to send a message being composed.
- :small:`type` :ref:`ComposeAttachment <compose.^compose^attachment>` — Represents an attachment in a message being composed.
- :small:`type` :ref:`ComposeDetails <compose.^compose^details>` — Used by various functions to represent the state of a message being composed. Note that functions using this type may have a partial implementation.
