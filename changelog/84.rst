============================
Changelog for Thunderbird 84
============================

The following WebExtension API changes were introduced in Thunderbird 84.


.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../browsingData.html">browsingData</a>
   </div>

- :small:`type` `RemovalOptions.cookieStoreId <../browsingData.html#browsing-data-removal-options-cookie-store-id>`__ — Only remove data associated with this specific cookieStoreId.


.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../composeAction.html">composeAction</a>
   </div>

- :small:`function` `getLabel <../composeAction.html#compose-action-get-label>`__ — Gets the label of the composeAction button. Returns :value:`null`, if no label has been set and the title is used.
- :small:`function` `setLabel <../composeAction.html#compose-action-set-label>`__ — Sets the label of the composeAction button. Can be used to set different values for the tooltip (defined by the title) and the label. Additionally, the label can be set to an empty string, not showing any label at all.
- :small:`property` `compose_action.default_label <../composeAction.html#compose-action-compose-action-default-label>`__ — The label of the composeAction button, defaults to its title. Can be set to an empty string to not display any label. If the containing toolbar is configured to display text only, the title will be used as fallback.


.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../messageDisplayAction.html">messageDisplayAction</a>
   </div>

- :small:`function` `getLabel <../messageDisplayAction.html#message-display-action-get-label>`__ — Gets the label of the messageDisplayAction button. Returns :value:`null`, if no label has been set and the title is used.
- :small:`function` `setLabel <../messageDisplayAction.html#message-display-action-set-label>`__ — Sets the label of the messageDisplayAction button. Can be used to set different values for the tooltip (defined by the title) and the label. Additionally, the label can be set to an empty string, not showing any label at all.
- :small:`property` `message_display_action.default_label <../messageDisplayAction.html#message-display-action-message-display-action-default-label>`__ — The label of the messageDisplayAction button, defaults to its title. Can be set to an empty string to not display any label. If the containing toolbar is configured to display text only, the title will be used as fallback.


.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../privacy.network.httpsOnlyMode.html">privacy.network.httpsOnlyMode</a>
   </div>

Allow users to query the mode for 'HTTPS-Only Mode'. This setting's value is of type HTTPSOnlyModeOption, defaulting to :code:`never`.
