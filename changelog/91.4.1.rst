================================
Changelog for Thunderbird 91.4.1
================================

The following WebExtension API changes were introduced in Thunderbird 91.4.1.


.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../cloudFile.html">cloudFile</a>
   </div>

- :small:`type` `CloudFileTemplateInfo <../cloudFile.html#cloud-file-cloud-file-template-info>`__ — Defines information to be used in the cloud file entry added to the message.


.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../messages.html">messages</a>
   </div>

- :small:`function` `query.queryInfo.attachment <../messages.html#messages-query-query-info-attachment>`__ — Whether the message has attachments, or not. Supports to specify a `messages.QueryRange <../messages.html#messages-query-range>`__ (min/max) instead of a simple boolean value (none/some).
