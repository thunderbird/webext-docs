============================
Changelog for Thunderbird 85
============================

The following WebExtension API changes were introduced in Thunderbird 85.


accounts
--------

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../accounts.html">accounts</a>
   </div>

- :small:`function` :ref:`getDefault <accounts.get^default>` — Returns the default account, or :value:`null` if it is not defined.
- :small:`function` :ref:`getDefaultIdentity <accounts.get^default^identity>` — Returns the default identity for an account, or :value:`null` if it is not defined.


messages
--------

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../messages.html">messages</a>
   </div>

- :small:`function` :ref:`query.queryInfo.headerMessageId <messages.query.query^info.header^message^id>` — Returns only messages with a Message-ID header matching this value.
