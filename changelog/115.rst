=============================
Changelog for Thunderbird 115
=============================

The following WebExtension API changes were introduced in Thunderbird 115.


browserAction
-------------

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../browserAction.html">browserAction</a>
   </div>

- :small:`property` :ref:`browser_action.allowed_spaces <browser^action.browser_action.allowed_spaces>` — Defines for which spaces the browserAction button will be added to Thunderbird's unified toolbar. Defaults to only allowing the browserAction in the :value:`mail` space. The :value:`default` space is for tabs that don't belong to any space. If this is an empty array, the browserAction button is shown in all spaces.
- :small:`property` :ref:`browser_action.default_windows <browser^action.browser_action.default_windows>` — Defines the windows, the browserAction button should appear in. Defaults to showing it only in the :value:`normal` Thunderbird window, but can also be shown in the :value:`messageDisplay` window.

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../commands.html">commands</a>

- :small:`event` :ref:`onChanged <commands.on^changed>` — Fired when a registered command's shortcut is changed.


sessions
--------

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../sessions.html">sessions</a>
   </div>

The sessions API allows to add tab related session data to Thunderbird's tabs, which will be restored on app restart.


spaces
------

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../spaces.html">spaces</a>
   </div>

The spaces API allows to manage built-in and custom spaces, and to add buttons for custom spaces to Thunderbird's spaces toolbar.

-------

.. raw:: html

- :small:`property` :ref:`session <storage.session>` — Items in the :code:`session` storage area are kept in memory, and only until the either browser or extension is closed or reloaded.


tabs
----

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../tabs.html">tabs</a>
   </div>

- :small:`function` :ref:`create.createProperties.cookieStoreId <tabs.create.create^properties.cookie^store^id>` — The `CookieStore <https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/API/contextualIdentities/ContextualIdentity#cookiestoreid>`__ id the new tab should use. Either a custom id created using the `contextualIdentities API <https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/API/contextualIdentities>`__, or a built-in one: :value:`firefox-default`, :value:`firefox-container-1`, :value:`firefox-container-2`, :value:`firefox-container-3`, :value:`firefox-container-4`, :value:`firefox-container-5`.
- :small:`function` :ref:`query.queryInfo.cookieStoreId <tabs.query.query^info.cookie^store^id>` — The `CookieStore <https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/API/contextualIdentities/ContextualIdentity#cookiestoreid>`__ id(s) used by the tabs. Either custom ids created using the `contextualIdentities API <https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/API/contextualIdentities>`__, or built-in ones: :value:`firefox-default`, :value:`firefox-container-1`, :value:`firefox-container-2`, :value:`firefox-container-3`, :value:`firefox-container-4`, :value:`firefox-container-5`.
- :small:`function` :ref:`query.queryInfo.spaceId <tabs.query.query^info.space^id>` — The id of the space the tabs should belong to.
- :small:`type` :ref:`Tab.cookieStoreId <tabs.^tab.cookie^store^id>` — The `CookieStore <https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/API/contextualIdentities/ContextualIdentity#cookiestoreid>`__ id used by the tab. Either a custom id created using the `contextualIdentities API <https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/API/contextualIdentities>`__, or a built-in one: :value:`firefox-default`, :value:`firefox-container-1`, :value:`firefox-container-2`, :value:`firefox-container-3`, :value:`firefox-container-4`, :value:`firefox-container-5`.
- :small:`type` :ref:`Tab.spaceId <tabs.^tab.space^id>` — The id of the space.
