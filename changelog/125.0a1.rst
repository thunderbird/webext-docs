=================================
Changelog for Thunderbird 125.0a1
=================================

The following WebExtension API changes were introduced in Thunderbird 125.0a1.


.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../compose.html">compose</a>
   </div>

- :small:`type` `ComposeDetails.isModified <../compose.html#compose-compose-details-is-modified>`__ — Whether the composer is considered modified by the user. A modified composer asks for confirmation, when it is closed.


.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../messages.html">messages</a>
   </div>

- :small:`function` `getFull.options.decrypt <../messages.html#messages-get-full-options-decrypt>`__ — Whether the message should be decrypted. If the message could not be decrypted, its parts are omitted. Defaults to :value:`true`.
- :small:`function` `getRaw.options.decrypt <../messages.html#messages-get-raw-options-decrypt>`__ — Whether the message should be decrypted. Throws, if the message could not be decrypted.
- :small:`type` `MessagePart.decryptionStatus <../messages.html#messages-message-part-decryption-status>`__ — The decryption status, only available for the root part.
