=============================
Changelog for Thunderbird 133
=============================

The following WebExtension API changes were introduced in Thunderbird 133.


messages
--------

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../messages.html">messages</a>
   </div>

- :small:`function` :ref:`getFull.options.decodeContent <messages.get^full.options.decode^content>` — Whether to decode quoted-printable or base64 encoded content of message parts. Defaults to :value:`true`.
- :small:`function` :ref:`getFull.options.decodeHeaders <messages.get^full.options.decode^headers>` — Whether to decode RFC 2047 encoded headers of message parts. Defaults to :value:`true`.
- :small:`type` :ref:`MessagePart.rawBody <messages.^message^part.raw^body>` — The raw content of the part. Only present if requested, see the :value:`decodeContent` option of :ref:`messages.getFull <messages.get^full>`.
- :small:`type` :ref:`MessagePart.rawHeaders <messages.^message^part.raw^headers>` — A *dictionary object* of raw part headers as *key-value* pairs, with the header name as *key*, and an array of headers as *value*. Only present if requested, see the :value:`decodeHeaders` option of :ref:`messages.getFull <messages.get^full>`.
