=============================
Changelog for Thunderbird 106
=============================

The following WebExtension API changes were introduced in Thunderbird 106.


commands
--------

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../commands.html">commands</a>
   </div>

- :small:`event` :ref:`onCommand.tab <commands.on^command.tab>` — The details of the active tab while the command occurred.


mailTabs
--------

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../mailTabs.html">mailTabs</a>
   </div>

- :small:`function` :ref:`setSelectedMessages <mail^tabs.set^selected^messages>` — Selects none, one or multiple messages. Opens collapsed threads to show the selection, if required.


messages
--------

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../messages.html">messages</a>
   </div>

- :small:`function` :ref:`import <messages.import>` — Imports a message into a folder. Supports local folders, POP and IMAP folders. Throws, if the destination folder already contains a message with the Message-ID of the message being imported.
- :small:`type` :ref:`MessageAttachment.message <messages.^message^attachment.message>` — A MessageHeader, if this attachment is a message.
- :small:`type` :ref:`MessageHeader.external <messages.^message^header.external>` — Whether this message is a real message or an external message (opened from a file or from an attachment).
- :small:`type` :ref:`MessageHeader.new <messages.^message^header.new>` — Whether the message has been received recently and is marked as new.
- :small:`type` :ref:`MessageProperties <messages.^message^properties>` — Message properties used in :ref:`messages.update <messages.update>` and :ref:`messages.import <messages.import>`. They can also be monitored by :ref:`messages.onUpdated <messages.on^updated>`.
