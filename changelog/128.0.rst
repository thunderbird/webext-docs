   </div>

- :small:`type` `ComposeDetails.additionalFccFolderId <../compose.html#compose-compose-details-additional-fcc-folder-id>`__ — An additional fcc folder which can be selected while composing the message. Cleared when set to :value:`null`. The permission :permission:`accountsRead` is required to use this property.
- :small:`type` `ComposeDetails.attachPublicPGPKey <../compose.html#compose-compose-details-attach-public-p-g-p-key>`__ — Whether the public OpenPGP key of the sending identity should be attached to the message.
- :small:`type` `ComposeDetails.isModified <../compose.html#compose-compose-details-is-modified>`__ — Whether the composer is considered modified by the user. A modified composer asks for confirmation, when it is closed.
- :small:`type` `ComposeDetails.overrideDefaultFccFolderId <../compose.html#compose-compose-details-override-default-fcc-folder-id>`__ — This value overrides the default fcc setting (defined by the used identity) for this message only. Either a `folders.MailFolderId <../folders.html#folders-mail-folder-id>`__ specifying the folder for the copy of the sent message, or an empty string to not save a copy at all. Reset when set to :value:`null`. The permission :permission:`accountsRead` is required to use this property.
- :small:`type` `ComposeDetails.selectedEncryptionTechnology <../compose.html#compose-compose-details-selected-encryption-technology>`__ — The selected encryption technology (:value:`OpenPGP` or :value:`S/MIME`) which is to be used to sign and/or encrypt the message. If the sending identity does not support encryption at all, this will be :value:`undefined`.
- :small:`type` `ComposeRecipient.nodeId <../compose.html#compose-compose-recipient-node-id>`__ — The ID of a contact or mailing list node from the :doc:`../addressBook.contacts` or :doc:`../addressBook.mailingLists`.

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../folders.html">folders</a>
   </div>

- :small:`function` `get <../folders.html#folders-get>`__ — Returns the specified folder.
- :small:`function` `getFolderCapabilities <../folders.html#folders-get-folder-capabilities>`__ — Get capability information about a folder.
- :small:`function` `getTagFolder <../folders.html#folders-get-tag-folder>`__ — Get one of the special virtual tag folders, which are virtual search folders and group messages from all mail accounts based on their tags. Throws if the requested folder does not exist.
- :small:`function` `getUnifiedFolder <../folders.html#folders-get-unified-folder>`__ — Get one of the special unified mailbox folders, which are virtual search folders and return the content from all mail accounts. Throws if the requested folder does not exist.
- :small:`function` `markAsRead <../folders.html#folders-mark-as-read>`__ — Marks all messages in a folder as read.
- :small:`function` `query <../folders.html#folders-query>`__ — Gets folders that match the specified properties, or all folders if no properties are specified.
- :small:`function` `update <../folders.html#folders-update>`__ — Updates properties of a folder.
- :small:`event` `onUpdated <../folders.html#folders-on-updated>`__ — Fired when properties of a folder have changed (:value:`specialUse` and :value:`isFavorite`).
- :small:`type` `MailFolder.id <../folders.html#folders-mail-folder-id>`__ — An identifier for the folder.
- :small:`type` `MailFolder.isFavorite <../folders.html#folders-mail-folder-is-favorite>`__ — Whether this folder is a favorite folder.
- :small:`type` `MailFolder.isRoot <../folders.html#folders-mail-folder-is-root>`__ — Whether this folder is a root folder.
- :small:`type` `MailFolder.isTag <../folders.html#folders-mail-folder-is-tag>`__ — Whether this folder is a virtual tag folder.
- :small:`type` `MailFolder.isUnified <../folders.html#folders-mail-folder-is-unified>`__ — Whether this folder is a unified mailbox folder.
- :small:`type` `MailFolder.isVirtual <../folders.html#folders-mail-folder-is-virtual>`__ — Whether this folder is a virtual search folder.
- :small:`type` `MailFolder.specialUse <../folders.html#folders-mail-folder-special-use>`__ — The special use of this folder. A folder can have multiple special uses.
- :small:`type` `MailFolderCapabilities <../folders.html#folders-mail-folder-capabilities>`__ — An object containing capability information about a folder.
- :small:`type` `MailFolderId <../folders.html#folders-mail-folder-id>`__ — A unique id representing a `folders.MailFolder <../folders.html#folders-mail-folder>`__ throughout a session. Renaming or moving a folder will invalidate its id.
- :small:`type` `MailFolderInfo.lastUsed <../folders.html#folders-mail-folder-info-last-used>`__ — Date the folder was last used. It is updated every time the folder was accessed, when the user moved or copied messages into the folder and when the folder received new messages. (precision: seconds).
- :small:`type` `MailFolderInfo.newMessageCount <../folders.html#folders-mail-folder-info-new-message-count>`__ — Number of new messages in this folder.
- :small:`type` `MailFolderInfo.quota <../folders.html#folders-mail-folder-info-quota>`__ — Quota information, if available.
- :small:`type` `MailFolderQuota <../folders.html#folders-mail-folder-quota>`__ — An object containing quota information.
- :small:`type` `MailFolderSpecialUse <../folders.html#folders-mail-folder-special-use>`__ — Supported values for the special use of a folder.
- :small:`type` `QueryRange <../folders.html#folders-query-range>`__ — An object defining a range for an integer value to be used in queries.
- :small:`property` `DEFAULT_MOST_RECENT_LIMIT <../folders.html#folders-d-e-f-a-u-l-t-m-o-s-t-r-e-c-e-n-t-l-i-m-i-t>`__ — The number of most recent folders used in Thunderbird's UI. Controlled by the :value:`mail.folder_widget.max_recent` preference.

   </div>

- :small:`type` `MenuIconDictionary <../menus.html#menus-menu-icon-dictionary>`__ — A *dictionary object* to specify paths for multiple icons in different sizes, so the best matching icon can be used, instead of scaling a standard icon to fit the pixel density of the user's display. Each entry is a *name-value* pair, with *name* being a size and *value* being a `menus.MenuIconPath <../menus.html#menus-menu-icon-path>`__.
- :small:`type` `OnClickData.selectedFolders <../menus.html#menus-on-click-data-selected-folders>`__ — The selected folders in the folder pane. Only available for the :value:`folder_pane` context. The :permission:`accountsRead` permission is required. The returned selection includes the folders which would be affected by a context action through Thunderbirds UI, which may not be the actuall selected folders. For example, if the user has multiple folders selected and opens the context menu for a folder outside that selection, only the folder for which the context menu was opened, is returned.
- :small:`type` `OnShowData.selectedFolders <../menus.html#menus-on-show-data-selected-folders>`__ — The selected folders in the folder pane. Only available for the :value:`folder_pane` context. The :permission:`accountsRead` permission is required. The returned selection includes the folders which would be affected by a context action through Thunderbirds UI, which may not be the actuall selected folders. For example, if the user has multiple folders selected and opens the context menu for a folder outside that selection, only the folder for which the context menu was opened, is returned.

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../messages.html">messages</a>
   </div>

- :small:`function` `abortList <../messages.html#messages-abort-list>`__ — Finalizes the specified list and terminates any process currently still adding messages.
- :small:`function` `deleteAttachments <../messages.html#messages-delete-attachments>`__ — Deletes the specified attachments and replaces them by placeholder text attachments with meta information about the original attachments and a :value:`text/x-moz-deleted` content type. This permanently modifies the message.
- :small:`function` `getFull.options.decrypt <../messages.html#messages-get-full-options-decrypt>`__ — Whether the message should be decrypted. If the message could not be decrypted, its parts are omitted. Defaults to :value:`true`.
- :small:`function` `getRaw.options.decrypt <../messages.html#messages-get-raw-options-decrypt>`__ — Whether the message should be decrypted. Throws, if the message could not be decrypted.
- :small:`function` `listInlineTextParts <../messages.html#messages-list-inline-text-parts>`__ — Lists all inline text parts of a message. These parts are not returned by `messages.listAttachments <../messages.html#messages-list-attachments>`__ and usually make up the readable content of the message, mostly with content type :value:`text/plain` or :value:`text/html`. If a message only includes a part with content type :value:`text/html`, the method `messengerUtilities.convertToPlainText <../messengerUtilities.html#messenger-utilities-convert-to-plain-text>`__ can be used to retreive a plain text version.
- :small:`function` `query.queryInfo.accountId <../messages.html#messages-query-query-info-account-id>`__ — Limits the search to the specified account(s). Accounts are searched in the specified order.
- :small:`function` `query.queryInfo.autoPaginationTimeout <../messages.html#messages-query-query-info-auto-pagination-timeout>`__ — Set the timeout in ms after which results should be returned, even if the nominal number of messages-per-page has not yet been reached. Defaults to :value:`1000` ms. Setting it to :value:`0` will disable auto-pagination.
- :small:`function` `query.queryInfo.folderId <../messages.html#messages-query-query-info-folder-id>`__ — Limits the search to the specified folder(s). Folders are searched in the specified order. The :permission:`accountsRead` permission is required.
- :small:`function` `query.queryInfo.junk <../messages.html#messages-query-query-info-junk>`__ — Returns only messages whith the specified junk state.
- :small:`function` `query.queryInfo.junkScore <../messages.html#messages-query-query-info-junk-score>`__ — Returns only messages with a junk score in the specified range.
- :small:`function` `query.queryInfo.messagesPerPage <../messages.html#messages-query-query-info-messages-per-page>`__ — Set the nominal number of messages-per-page for this query. Defaults to :value:`100` messages.
- :small:`function` `query.queryInfo.new <../messages.html#messages-query-query-info-new>`__ — Returns only messages with the specified new state.
- :small:`function` `query.queryInfo.read <../messages.html#messages-query-query-info-read>`__ — Returns only messages with the specified read state.
- :small:`function` `query.queryInfo.returnMessageListId <../messages.html#messages-query-query-info-return-message-list-id>`__ — The *messageListId* is usually returned together with the first page, after some messages have been found. Enabling this option will change the return value of this function and return the *messageListId* directly.
- :small:`function` `query.queryInfo.size <../messages.html#messages-query-query-info-size>`__ — Returns only messages with a size in the specified byte range.
- :small:`type` `InlineTextPart <../messages.html#messages-inline-text-part>`__ — An inline part with content type :value:`text/*`. These parts are not returned by `messages.listAttachments <../messages.html#messages-list-attachments>`__ and usually make up the readable content of the message, mostly with content type :value:`text/plain` or :value:`text/html`
- :small:`type` `MessageAttachment.contentId <../messages.html#messages-message-attachment-content-id>`__ — The content-id of this part. Available for related parts, which are referenced from other places inside the same message (e.g. inline images).
- :small:`type` `MessageId <../messages.html#messages-message-id>`__ — A unique id representing a `messages.MessageHeader <../messages.html#messages-message-header>`__ and the associated message. This id doesn’t refer to the Message-ID email header. It is an internal tracking number that does not remain after a restart. Nor does it follow an email that has been moved to a different folder.
- :small:`type` `MessagePart.decryptionStatus <../messages.html#messages-message-part-decryption-status>`__ — The decryption status, only available for the root part.
- :small:`type` `QueryRange <../messages.html#messages-query-range>`__ — An object defining a range.
