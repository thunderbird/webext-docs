==============================
Changelog for Thunderbird 91.0
==============================

The following WebExtension API changes were introduced in Thunderbird 91.0.


.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../accounts.html">accounts</a>
   </div>

- :small:`function` `get.includeSubFolders <../accounts.html#accounts-get-include-sub-folders>`__ — Specifies whether the `folders.MailFolder <../folders.html#folders-mail-folder>`__ in the :value:`rootFolder` property of the returned `accounts.MailAccount <../accounts.html#accounts-mail-account>`__ should populate its :value:`subFolders` property, and include all (nested!) subfolders. Defaults to :value:`false`.
- :small:`function` `getDefault.includeSubFolders <../accounts.html#accounts-get-default-include-sub-folders>`__ — Specifies whether the `folders.MailFolder <../folders.html#folders-mail-folder>`__ in the :value:`rootFolder` property of the default `accounts.MailAccount <../accounts.html#accounts-mail-account>`__ should populate its :value:`subFolders` property, and include all (nested!) subfolders. Defaults to :value:`false`
- :small:`function` `list.includeSubFolders <../accounts.html#accounts-list-include-sub-folders>`__ — Specifies whether the `folders.MailFolder <../folders.html#folders-mail-folder>`__ in the :value:`rootFolder` property of each found `accounts.MailAccount <../accounts.html#accounts-mail-account>`__ should populate its :value:`subFolders` property, and include all (nested!) subfolders. Defaults to :value:`false`.
- :small:`type` `MailAccount <../accounts.html#accounts-mail-account>`__ — An object describing a mail account, as returned for example by the `accounts.list <../accounts.html#accounts-list>`__ and `accounts.get <../accounts.html#accounts-get>`__ methods.

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../compose.html">compose</a>
   </div>

- :small:`function` `getComposeState <../compose.html#compose-get-compose-state>`__ — Returns information about the current state of the message composer.
- :small:`function` `sendMessage <../compose.html#compose-send-message>`__ — Sends the message currently being composed. If the send mode is not specified or set to :value:`default`, the message will be send directly if the user is online and placed in the users outbox otherwise. The returned Promise fulfills once the message has been successfully sent or placed in the user's outbox. Throws when the send process has been aborted by the user, by an `compose.onBeforeSend <../compose.html#compose-on-before-send>`__ event or if there has been an error while sending the message to the outgoing mail server.
- :small:`event` `onComposeStateChanged <../compose.html#compose-on-compose-state-changed>`__ — Fired when the state of the message composer changed.
- :small:`type` `ComposeDetails.from <../compose.html#compose-compose-details-from>`__ — *Caution*: Setting a value for :value:`from` does not change the used identity, it overrides the *From* header. Many email servers do not accept emails where the *From* header does not match the sender identity. Must be set to exactly one valid email address.
- :small:`type` `ComposeDetails.type <../compose.html#compose-compose-details-type>`__ — Read-only. The type of the message being composed, depending on how the compose window was opened by the user.
- :small:`type` `ComposeState <../compose.html#compose-compose-state>`__ — Represent the state of the message composer.


.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../composeAction.html">composeAction</a>
   </div>

- :small:`type` `ImageDataDictionary <../composeAction.html#compose-action-image-data-dictionary>`__ — A *dictionary object* to specify multiple `ImageData <https://developer.mozilla.org/en-US/docs/Web/API/ImageData>`__ objects in different sizes, so the icon does not have to be scaled for a device with a different pixel density. Each entry is a *name-value* pair with *value* being an `ImageData <https://developer.mozilla.org/en-US/docs/Web/API/ImageData>`__ object, and *name* its size.
- :small:`property` `compose_action.type <../composeAction.html#compose-action-compose-action-type>`__ — Specifies the type of the button. Default type is :value:`button`.


.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../folders.html">folders</a>
   </div>

- :small:`function` `copy <../folders.html#folders-copy>`__ — Copies the given source folder into the given destination folder. Throws if the destination already contains a folder with the name of the source folder.
- :small:`function` `getFolderInfo <../folders.html#folders-get-folder-info>`__ — Get additional information about a folder.
- :small:`function` `getParentFolders <../folders.html#folders-get-parent-folders>`__ — Get all parent folders as a flat ordered array. The first array entry is the direct parent.
- :small:`function` `getSubFolders <../folders.html#folders-get-sub-folders>`__ — Get the subfolders of the specified folder.
- :small:`function` `move <../folders.html#folders-move>`__ — Moves the given source folder into the given destination folder. Throws if the destination already contains a folder with the name of the source folder.
- :small:`event` `onCopied <../folders.html#folders-on-copied>`__ — Fired when a folder has been copied.
- :small:`event` `onCreated <../folders.html#folders-on-created>`__ — Fired when a folder has been created.
- :small:`event` `onDeleted <../folders.html#folders-on-deleted>`__ — Fired when a folder has been deleted.
- :small:`event` `onFolderInfoChanged <../folders.html#folders-on-folder-info-changed>`__ — Fired when certain information of a folder have changed. Bursts of message count changes are collapsed to a single event.
- :small:`event` `onMoved <../folders.html#folders-on-moved>`__ — Fired when a folder has been moved.
- :small:`event` `onRenamed <../folders.html#folders-on-renamed>`__ — Fired when a folder has been renamed.
- :small:`type` `MailFolderInfo <../folders.html#folders-mail-folder-info>`__ — An object containing additional information about a folder.
