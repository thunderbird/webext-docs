=============================
Changelog for Thunderbird 149
=============================

The following WebExtension API changes were introduced in Thunderbird 149.


contacts
--------

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../contacts.html">contacts</a>
   </div>

- :small:`event` :ref:`onManyCreated <contacts.on^many^created>` — Fired when a large number of contacts are added. The contacts are not emitted for performance reasons. The event indicates significant changes, and consumers should rebuild any cached representation of the address book.


tabs
----

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../tabs.html">tabs</a>
   </div>

- :small:`type` :ref:`Tab.splitViewId <tabs.^tab.split^view^id>` — The ID of the Split View that the tab belongs to. -1 if the tab does not belong to a split view.
