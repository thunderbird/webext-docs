================================
Changelog for Thunderbird 78.6.1
================================

The following WebExtension API changes were introduced in Thunderbird 78.6.1.


composeAction
-------------

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../composeAction.html">composeAction</a>
   </div>

- :small:`function` :ref:`getLabel <compose^action.get^label>` — Gets the label of the composeAction button. Returns :value:`null`, if no label has been set and the title is used.
- :small:`function` :ref:`setLabel <compose^action.set^label>` — Sets the label of the composeAction button. Can be used to set different values for the tooltip (defined by the title) and the label. Additionally, the label can be set to an empty string, not showing any label at all.
- :small:`property` :ref:`compose_action.default_label <compose^action.compose_action.default_label>` — The label of the composeAction button, defaults to its title. Can be set to an empty string to not display any label. If the containing toolbar is configured to display text only, the title will be used as fallback.
