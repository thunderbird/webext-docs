============================
Changelog for Thunderbird 83
============================

The following WebExtension API changes were introduced in Thunderbird 83.


compose
-------

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../compose.html">compose</a>
   </div>

- :small:`type` :ref:`ComposeAttachment.size <compose.^compose^attachment.size>` — The size in bytes of this attachment. Read-only.


contacts
--------

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../contacts.html">contacts</a>
   </div>

- :small:`type` :ref:`PropertyChange <contacts.^property^change>` — A dictionary of changed properties. Keys are the property name that changed, values are an object containing :value:`oldValue` and :value:`newValue`. Values can be either a string or :value:`null`.


menus
-----

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../menus.html">menus</a>
   </div>

- :small:`type` :ref:`OnClickData.attachments <menus.^on^click^data.attachments>` — The selected attachments. The :permission:`compose` permission is required to return attachments of a message being composed. The :permission:`messagesRead` permission is required to return attachments of displayed messages.
