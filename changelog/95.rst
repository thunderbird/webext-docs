============================
Changelog for Thunderbird 95
============================

The following WebExtension API changes were introduced in Thunderbird 95.


browserSettings.overrideContentColorScheme
------------------------------------------

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../browserSettings.overrideContentColorScheme.html">browserSettings.overrideContentColorScheme</a>
   </div>

This setting controls whether a light or dark color scheme overrides the page's preferred color scheme.


compose
-------

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../compose.html">compose</a>
   </div>

- :small:`type` :ref:`ComposeDetails.relatedMessageId <compose.^compose^details.related^message^id>` — The id of the original message (in case of draft, template, forward or reply). Read-only. Is :value:`undefined` in all other cases or if the original message was opened from file. The :permission:`messagesRead` permission is required to use this property.


privacy.network.globalPrivacyControl
------------------------------------

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../privacy.network.globalPrivacyControl.html">privacy.network.globalPrivacyControl</a>
   </div>

Allow users to query the status of 'Global Privacy Control'. This setting's value is of type boolean, defaulting to :code:`false`.
