=================================
Changelog for Thunderbird 102.3.3
=================================

The following WebExtension API changes were introduced in Thunderbird 102.3.3.


browserAction
-------------

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../browserAction.html">browserAction</a>
   </div>

- :small:`property` :ref:`browser_action.default_windows <browser^action.browser_action.default_windows>` — Defines the windows, the browserAction button should appear in. Defaults to showing it only in the :value:`normal` Thunderbird window, but can also be shown in the :value:`messageDisplay` window.


commands
--------

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../commands.html">commands</a>
   </div>

- :small:`event` :ref:`onCommand.tab <commands.on^command.tab>` — The details of the active tab while the command occurred.


mailTabs
--------

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../mailTabs.html">mailTabs</a>
   </div>

- :small:`function` :ref:`setSelectedMessages <mail^tabs.set^selected^messages>` — Selects none, one or multiple messages. Opens collapsed threads to show the selection, if required.
