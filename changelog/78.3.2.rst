================================
Changelog for Thunderbird 78.3.2
================================

The following WebExtension API changes were introduced in Thunderbird 78.3.2.


compose
-------

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../compose.html">compose</a>
   </div>

- :small:`type` :ref:`ComposeDetails.attachments <compose.^compose^details.attachments>` — Only used in the begin* functions. Attachments to add to the message.


messageDisplay
--------------

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../messageDisplay.html">messageDisplay</a>
   </div>

- :small:`function` :ref:`getDisplayedMessages <message^display.get^displayed^messages>` — Gets an array of the currently displayed messages in the specified tab (even if the tab itself is currently not visible), or the currently active tab. The array is empty if no messages are displayed.
- :small:`event` :ref:`onMessagesDisplayed <message^display.on^messages^displayed>` — Fired when either a single message is displayed or when multiple messages are displayed, whether in a 3-pane tab, a message tab, or a message window.
