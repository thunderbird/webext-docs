============================
Changelog for Thunderbird 86
============================

The following WebExtension API changes were introduced in Thunderbird 86.

-----

The theme API allows for customization of Thunderbird's visual elements.


theme
-----

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../theme.html">theme</a>
   </div>

- :small:`property` :ref:`theme_experiment <theme.theme_experiment>` — A theme experiment allows modifying the user interface of Thunderbird beyond what is currently possible using the built-in color, image and property keys of :ref:`theme.ThemeType <theme.^theme^type>`. These experiments are a precursor to proposing new theme features for inclusion in Thunderbird. Experimentation is done by mapping internal CSS color, image and property variables to new theme keys and using them in :ref:`theme.ThemeType <theme.^theme^type>` and by loading additional style sheets to add new CSS variables, extending the theme-able areas of Thunderbird. Can be used in static and dynamic themes.
