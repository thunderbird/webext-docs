============================
Changelog for Thunderbird 96
============================

The following WebExtension API changes were introduced in Thunderbird 96.


cloudFile
---------

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../cloudFile.html">cloudFile</a>
   </div>

- :small:`type` :ref:`CloudFileTemplateInfo <cloud^file.^cloud^file^template^info>` — Defines information to be used in the cloud file entry added to the message.


messages
--------

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../messages.html">messages</a>
   </div>

- :small:`function` :ref:`query.queryInfo.attachment <messages.query.query^info.attachment>` — Whether the message has attachments, or not. Supports to specify a :ref:`messages.QueryRange <messages.^query^range>` (min/max) instead of a simple boolean value (none/some).
