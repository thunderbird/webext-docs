===============================
Changelog for Thunderbird 115.0
===============================

The following WebExtension API changes were introduced in Thunderbird 115.0.


.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../browserAction.html">browserAction</a>
   </div>

- :small:`function` `getBadgeBackgroundColor.details.tabId <../browserAction.html#browser-action-get-badge-background-color-details-tab-id>`__ — Specifies for which tab the badge background color should be retrieved. If no tab is specified, the global value is retrieved.
- :small:`function` `getBadgeBackgroundColor.details.windowId <../browserAction.html#browser-action-get-badge-background-color-details-window-id>`__ — Will throw an error if used.
- :small:`function` `getBadgeText.details.tabId <../browserAction.html#browser-action-get-badge-text-details-tab-id>`__ — Specifies for which tab the badge text should be retrieved. If no tab is specified, the global value is retrieved.
- :small:`function` `getBadgeText.details.windowId <../browserAction.html#browser-action-get-badge-text-details-window-id>`__ — Will throw an error if used.
- :small:`function` `getLabel.details.tabId <../browserAction.html#browser-action-get-label-details-tab-id>`__ — Specifies for which tab the label should be retrieved. If no tab is specified, the global value is retrieved.
- :small:`function` `getLabel.details.windowId <../browserAction.html#browser-action-get-label-details-window-id>`__ — Will throw an error if used.
- :small:`function` `getPopup.details.tabId <../browserAction.html#browser-action-get-popup-details-tab-id>`__ — Specifies for which tab the popup document should be retrieved. If no tab is specified, the global value is retrieved.
- :small:`function` `getPopup.details.windowId <../browserAction.html#browser-action-get-popup-details-window-id>`__ — Will throw an error if used.
- :small:`function` `getTitle.details.tabId <../browserAction.html#browser-action-get-title-details-tab-id>`__ — Specifies for which tab the title should be retrieved. If no tab is specified, the global value is retrieved.
- :small:`function` `getTitle.details.windowId <../browserAction.html#browser-action-get-title-details-window-id>`__ — Will throw an error if used.
- :small:`function` `isEnabled.details.tabId <../browserAction.html#browser-action-is-enabled-details-tab-id>`__ — Specifies for which tab the state should be retrieved. If no tab is specified, the global value is retrieved.
- :small:`function` `isEnabled.details.windowId <../browserAction.html#browser-action-is-enabled-details-window-id>`__ — Will throw an error if used.
- :small:`function` `openPopup.options <../browserAction.html#browser-action-open-popup-options>`__ — An object with information about the popup to open.
- :small:`property` `browser_action.allowed_spaces <../browserAction.html#browser-action-browser-action-allowed-spaces>`__ — Defines for which spaces the browserAction button will be added to Thunderbird's unified toolbar. Defaults to only allowing the browserAction in the :value:`mail` space. The :value:`default` space is for tabs that don't belong to any space. If this is an empty array, the browserAction button is shown in all spaces.

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../messages.html">messages</a>
   </div>

- :small:`function` `import <../messages.html#messages-import>`__ — Imports a message into a folder. Supports local folders, POP and IMAP folders. Throws, if the destination folder already contains a message with the Message-ID of the message being imported.
- :small:`function` `openAttachment <../messages.html#messages-open-attachment>`__ — Opens the specified attachment.
- :small:`type` `MessageAttachment.message <../messages.html#messages-message-attachment-message>`__ — A MessageHeader, if this attachment is a message.
- :small:`type` `MessageHeader.external <../messages.html#messages-message-header-external>`__ — Whether this message is a real message or an external message (opened from a file or from an attachment).
- :small:`type` `MessageHeader.new <../messages.html#messages-message-header-new>`__ — Whether the message has been received recently and is marked as new.
- :small:`type` `MessageProperties <../messages.html#messages-message-properties>`__ — Message properties used in `messages.update <../messages.html#messages-update>`__ and `messages.import <../messages.html#messages-import>`__. They can also be monitored by `messages.onUpdated <../messages.html#messages-on-updated>`__.

- :small:`function` `create.createProperties.cookieStoreId <../tabs.html#tabs-create-create-properties-cookie-store-id>`__ — The `CookieStore <https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/API/contextualIdentities/ContextualIdentity#cookiestoreid>`__ id the new tab should use. Either a custom id created using the `contextualIdentities API <https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/API/contextualIdentities>`__, or a built-in one: :value:`firefox-default`, :value:`firefox-container-1`, :value:`firefox-container-2`, :value:`firefox-container-3`, :value:`firefox-container-4`, :value:`firefox-container-5`.
- :small:`function` `query.queryInfo.cookieStoreId <../tabs.html#tabs-query-query-info-cookie-store-id>`__ — The `CookieStore <https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/API/contextualIdentities/ContextualIdentity#cookiestoreid>`__ id(s) used by the tabs. Either custom ids created using the `contextualIdentities API <https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/API/contextualIdentities>`__, or built-in ones: :value:`firefox-default`, :value:`firefox-container-1`, :value:`firefox-container-2`, :value:`firefox-container-3`, :value:`firefox-container-4`, :value:`firefox-container-5`.
- :small:`function` `query.queryInfo.spaceId <../tabs.html#tabs-query-query-info-space-id>`__ — The id of the space the tabs should belong to.
- :small:`event` `onActivated.activeInfo.previousTabId <../tabs.html#tabs-on-activated-active-info-previous-tab-id>`__ — The ID of the tab that was previously active, if that tab is still open.
- :small:`type` `Tab.cookieStoreId <../tabs.html#tabs-tab-cookie-store-id>`__ — The `CookieStore <https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/API/contextualIdentities/ContextualIdentity#cookiestoreid>`__ id used by the tab. Either a custom id created using the `contextualIdentities API <https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/API/contextualIdentities>`__, or a built-in one: :value:`firefox-default`, :value:`firefox-container-1`, :value:`firefox-container-2`, :value:`firefox-container-3`, :value:`firefox-container-4`, :value:`firefox-container-5`.
- :small:`type` `Tab.spaceId <../tabs.html#tabs-tab-space-id>`__ — The id of the space.
