.. role:: small

=============================
Changelog for Thunderbird 136
=============================

The following WebExtension API changes were introduced in Thunderbird 136.


.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../messages.tags.html">messages.tags</a>
   </div>

- :small:`event` `onCreated <../messages.tags.html#messages-tags-on-created>`__ — Fired when a new message tag has been created.
- :small:`event` `onDeleted <../messages.tags.html#messages-tags-on-deleted>`__ — Fired when a message tag has been deleted.
- :small:`event` `onUpdated <../messages.tags.html#messages-tags-on-updated>`__ — Fired when one or more properties of a message tag have been updated.


.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../runtime.html">runtime</a>
   </div>

- :small:`event` `onUserScriptConnect <../runtime.html#runtime-on-user-script-connect>`__ — Fired when a connection is made from a USER_SCRIPT world registered through the userScripts API.
- :small:`event` `onUserScriptMessage <../runtime.html#runtime-on-user-script-message>`__ — Fired when a message is sent from a USER_SCRIPT world registered through the userScripts API.


.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../spaces.html">spaces</a>
   </div>

- :small:`type` `SpaceTabProperties.linkHandler <../spaces.html#spaces-space-tab-properties-link-handler>`__ — Thunderbird is a mail client, not a browser. It is possible to load a web page, but opening follow-up pages through hyperlinks should be handled by the user's default browser. This property specifies to what extent this behavior should be enforced. The default :value:`balanced` link handler will open links to the same host directly in Thunderbird, everything else will be opened in the user's default browser. A :value:`relaxed` link handler will open all links inside of Thunderbird, a :value:`strict` link handler will open all links in the user's default browser, except links to the same page.
