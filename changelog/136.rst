=============================
Changelog for Thunderbird 136
=============================

The following WebExtension API changes were introduced in Thunderbird 136.


.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../runtime.html">runtime</a>
   </div>

- :small:`event` `onUserScriptConnect <../runtime.html#runtime-on-user-script-connect>`__ — Fired when a connection is made from a USER_SCRIPT world registered through the userScripts API.
- :small:`event` `onUserScriptMessage <../runtime.html#runtime-on-user-script-message>`__ — Fired when a message is sent from a USER_SCRIPT world registered through the userScripts API.
