=============================
Changelog for Thunderbird 112
=============================

The following WebExtension API changes were introduced in Thunderbird 112.


webRequest
----------

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../webRequest.html">webRequest</a>
   </div>

- :small:`type` :ref:`SecurityInfo.usedDelegatedCredentials <web^request.^security^info.used^delegated^credentials>` — True if the TLS connection used Delegated Credentials.
- :small:`type` :ref:`SecurityInfo.usedEch <web^request.^security^info.used^ech>` — True if the TLS connection used Encrypted Client Hello.
- :small:`type` :ref:`SecurityInfo.usedOcsp <web^request.^security^info.used^ocsp>` — True if the TLS connection made OCSP requests.
- :small:`type` :ref:`SecurityInfo.usedPrivateDns <web^request.^security^info.used^private^dns>` — True if the TLS connection used a privacy-preserving DNS transport like DNS-over-HTTPS.
