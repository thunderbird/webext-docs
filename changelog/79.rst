============================
Changelog for Thunderbird 79
============================

The following WebExtension API changes were introduced in Thunderbird 79.


.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../compose.html">compose</a>
   </div>

- :small:`event` `onIdentityChanged <../compose.html#compose-on-identity-changed>`__ — Fired when the user changes the identity that will be used to send a message being composed.


.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../windows.html">windows</a>
   </div>

- :small:`type` `GetInfo <../windows.html#windows-get-info>`__ — Specifies additional requirements for the returned windows.
