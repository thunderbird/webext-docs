=============================
Changelog for Thunderbird 148
=============================

The following WebExtension API changes were introduced in Thunderbird 148.


mailTabs
--------

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../mailTabs.html">mailTabs</a>
   </div>

- :small:`function` :ref:`getListedMessages.options.sortOrder <mail^tabs.get^listed^messages.options.sort^order>` — The sort order for the returned messages. Ignored if :value:`sortType` is not specified.
- :small:`function` :ref:`getListedMessages.options.sortType <mail^tabs.get^listed^messages.options.sort^type>` — Specifies how the returned messages should be sorted. This does not change the actual sort of the displayed messages. Default sort order is :value:`descending`, if not specified otherwise. Returning sorted messages is faster than manually sorting the messages afterwards, but slower than returning the messages in their original order.
