Changelog for Thunderbird 140
=============================

The following WebExtension API changes were introduced in Thunderbird 140.


.. raw:: html

   <div class="changelog-api-header">

- :small:`property` `oauth_provider <../oauthProvider.html#oauth-provider-oauth-provider>`__ — Describes an OAuth authentication provider for Thunderbird to use when connecting to mail/address book/calendar services. You will need to have a client ID registered with the provider to use this API.
