=============================
Changelog for Thunderbird 105
=============================

The following WebExtension API changes were introduced in Thunderbird 105.


action
------

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../action.html">action</a>
   </div>

Use the action API to add a button to Thunderbird's unified toolbar. In addition to its icon, an action button can also have a tooltip, a badge, and a popup.


compose
-------

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../compose.html">compose</a>
   </div>

- :small:`event` :ref:`onAfterSave <compose.on^after^save>` — Fired when saving a message as draft or template succeeded or failed.
- :small:`event` :ref:`onAfterSend <compose.on^after^send>` — Fired when sending a message succeeded or failed.
