=============================
Changelog for Thunderbird 114
=============================

The following WebExtension API changes were introduced in Thunderbird 114.


messageDisplay
--------------

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../messageDisplay.html">messageDisplay</a>
   </div>

- :small:`function` :ref:`open.openProperties.file <message^display.open.open^properties.file>` — The DOM file object of a message to be opened.


messages
--------

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../messages.html">messages</a>
   </div>

- :small:`function` :ref:`openAttachment <messages.open^attachment>` — Opens the specified attachment.


spaces
------

.. raw:: html

   <div class="changelog-api-header">
     <span class="changelog-api-label">api</span>
     <a href="../spaces.html">spaces</a>
   </div>

The spaces API allows to manage built-in and custom spaces, and to add buttons for custom spaces to Thunderbird's spaces toolbar.
